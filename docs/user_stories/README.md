# User Stories Working Draft

Status: discovery in progress.

## Codebase signals already identified

From repository history (`origin/main`) and project docs, this product appears to be **KCards**: a Flutter app for organizing and studying knowledge cards and linked question cards in a directory tree.

Observed capabilities from existing documentation/code:
- Local-first guest mode
- Optional authenticated/cloud-backed mode via Firebase
- Directory tree management
- Knowledge card CRUD
- Question card CRUD linked to knowledge cards
- Image attachments
- Study sessions and flip-card review
- Study progress tracking
- Export/import of directory subtrees
